# 4 Mar 2026 – DeepSeek 3 – Multi‑track stem visualization for Piyut videos


We extended the visualisation system to handle Suno’s multi‑track stem exports.  The previous single‑waveform `AudioVisualization` class was split into `TrackDisplay` and `MultiTrackDisplay`, giving each stem its own visual lane while keeping them temporally locked.  The `Composition` class gained automatic stem‑folder detection and sorting, so dropping a set of stems into a project directory would trigger a stacked waveform render without any manual configuration.  The `generate_visualization` function was modified to conditionally switch between single and multi‑track modes, keeping backward compatibility with the existing mono‑track piyut videos.
