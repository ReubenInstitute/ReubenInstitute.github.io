# 20 Sep 2026 – DeepSeek 4.1, Claude (Code) Sonnet 5 – Parashot Studio: fixing video export

*Studio, ParashahSeries, Media, Code*

`psalm-studio.py` already exported videos, but `parashot-studio.py` could not. The task was to find out why and fix it.

### Diagnosis

The old `studio.py` calls the same `EpisodeVideo` code, so parashot video export very likely never worked there either. Three problems were found:

* `EpisodeParagraphVersePlate.footer` looked verses up by chapter verse number as if it were a position in the episode. Episode 1.2 and most others raised `IndexError`.
* Plate file names used the chapter verse number, so an episode crossing a chapter boundary would overwrite plates.
* Videos went to the Studio root at the 270x480 test size.

### Fixing the episode export

Plates, footers and the video now identify a verse by its position in the episode, while the yellow highlight still matches by verse number. Videos go to `output/torah/` at 720x1280 (`Media.SDV`). The parashot list link pointed at the old `/bible/parashot/N`, and now points at `/N`.

Slides strip cantillation and Hebrew punctuation but keep the maqaf. `Hebrew.presentation()` turns the maqaf into a space, so it is not used. Parashah text uses SBL Hebrew on the slides and in the web interface, with the font copied from `Scriptures/fonts/` and a `.sbl` class on the web pages so the psalm pages are unaffected.

### The full-parashah export

The old `ParashahVideo` and `ParashahAudio` were stale, so they were rewritten to export each episode and join the results, with a new route, `/generate/video/N/full`. The first full export died when the kernel killed ffmpeg for running out of memory on the 1 GB box. Episode video now encodes one small clip per verse, joins them, then adds the audio, which dropped the `raw=True` background option.

### Content

`Hebrew.normalize` was run over `text/parashot/*.md` in StyledScriptures. 43 of 48 files changed, but it only reorders combining marks and doesn't alter the text.

### Result

Parashah 12 (16 min 41 s) exported at 720x1280 and is at `http://104.248.53.132/public/torah-12.mp4`, with the audio at `parashah-12.mp3` beside it. Duration and audio match, though it has not been watched in full.

Studio got one commit of 10 files, and StyledScriptures one content-only commit, `afa279c`, both pushed. `automate.py`, `output` and the `ReuvenSerif` backups were left uncommitted, as asked. The other session's commit `ccdd7c7` (the FrankCurledLamedRI font) touched different lines, so nothing conflicted.

### What is still open

* The `/N/pdf` link on the parashah page still gives a 404.
* The last line in a highlight frame looks slightly doubled, because the highlight image redraws every word and the shadows overlap. This predates the changes.
* Only episode 1.2 and parashah 12 were exercised. An episode spanning two chapters has not been tried, and in that case verses sharing a number would both be highlighted.
* The memory note for the psalm highlight work still says "Parashot untouched and still broken", and can be updated.
